## Iris v0.1.0

First release. Tweakable base icons and alphabet with font, SVG, PNG and kit export.

### Icons
- 874 icons in 21 categories, searchable and filterable.
- Restyle all of them at once: weight, ends, corners, color, solid or outline, rotate, flip.
- Circle, rounded or square badge; flat or long drop shadow.
- Export one icon as SVG, PNG, WebP or JPG; export the set as an icon font, SVG zip, or a FontAwesome-style kit (`iris.css`, one-tag `iris-kit.js`, SVG sprite, demo page).

### Typeface
- Base Latin glyphs: A-Z, a-z, 0-9, punctuation.
- Style controls: contrast, serifs, slant, width, spacing, stroke ends, corners; presets for sans, serif, slab and script-style.
- Family export contains all nine weights (Thin 100 to Black 900) as `.otf` with `@font-face` CSS, a one-tag kit script and a demo page. Designer and license are written into the font.

### Known limits
- Fonts are single color; badge and shadow apply to icon SVG/PNG only.
- Script-style is slanted contrast only, not connected script.
- Some icons are rough drafts and will be redrawn.

### Download
`iris-portal-v0.1.0.zip` is the static portal (open `index.html`). Live site: https://asticore.github.io/Iris/
